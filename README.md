# FitThumb

Ultra-simple one-tap fitness tracker built around the Lazy Thumb + 6-step habit framework.

## Core idea
- **One photo** → protein estimate (Cal AI style)
- **One tap** → log a set with previous weight/reps pre-filled (Hevy/GymAdapt style)
- Defaults everywhere, variable rewards, streaks, and progress you don’t want to lose

## Live prototype
Open `index.html` in a browser or deploy to Vercel.

Inspired by PeptIQ’s one-tap logging + José Gonçalves’ 6-step framework (Itch, Lazy Thumb, Paved Path, Slot Machine, Bottomless Pit, Piggy Bank).
